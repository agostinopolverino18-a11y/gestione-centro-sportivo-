# gestione-centro-sportivo- 
 Descrizione
Questo progetto ha lo scopo di modellare un sistema per la gestione di un centro sportivo.

Il sistema permette di gestire:
- utenti (clienti e istruttori)
- corsi sportivi
- prenotazioni
- pagamenti
- strutture del centro sportivo

Obiettivo
L'obiettivo del progetto è progettare la struttura software utilizzando i principi della Programmazione Orientata agli Oggetti (POO).

Tecnologie utilizzate
- Java
- Maven

Stato del progetto
Il progetto è attualmente in fase di analisi e progettazione
